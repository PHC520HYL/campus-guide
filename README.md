## 项目介绍

本项目为 **江西电力职业技术学院 2026 新生入学指南**，由在校学长整理维护。

以**场景化时间线**为引导，从新生收到录取通知书开始，依次覆盖：

- 📦 **出发前** — 证件清单、缴费、学费、交通、快递地址
- 🏁 **报到日** — 报到流程、校园卡绑定、绿色通道
- 📚 **开学后** — 军训、专业介绍、社团、图书馆、选课
- 🎓 **校园日常** — 食堂、宿舍、超市、快递、运动、校医院
- 🛒 **校园特惠** — 驾校推荐、电话卡、专升本、国网培训、兼职等赚钱渠道

## 功能亮点

| 功能 | 说明 |
|---|---|
| 场景化时间线 | 5个阶段逐步引导，符合新生认知路径 |
| 全文搜索 | 支持关键词模糊匹配，快速定位信息 |
| 详情弹窗 | 点击卡片直接查看完整内容 |
| 每日签到 | 签到积分、用户等级，增强用户粘度 |
| 分享卡片 | Canvas 生成品牌海报，一键保存分享 |
| 品牌弹窗 | 首次访问展示学长联系方式 |
| 移动端优化 | 响应式设计，适配手机/平板 |

---

## 技术栈

- **纯原生 HTML/CSS/JS**，零框架依赖
- **轻量化**：单文件约 200KB，无外部图片/字体请求
- **渐进增强**：关闭 JS 仍可阅读核心内容
